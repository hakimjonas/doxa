# doxa

`doxa` is the Dart kernel package for the Doxa dependently typed proof checker.
It provides parsing-independent core terms, elaboration, type checking,
normalization by evaluation, and diagnostics used by `doxa_tooling`.

The package requires Dart 3.7 or later and is licensed under GPL-3.0-or-later.
Repository documentation, examples, and editor integrations are available at
<https://github.com/hakimjonas/doxa>.
