## What's Complete

### Tooling (Phases 0-3c, branch `doxa-tooling`)
- **Phase 0**: Tokenizer (`rumil_tokens` grammar), unified `tok-*` CSS highlighting, server-side + client-side integration
- **Phase 1**: GreenNode CST (token/syntax alphabets, lossless parse tree, RedTree position queries, incremental reparse stub)
- **Phase 2**: Structured JSON output (`CheckOutput`/`CheckSuccess`/`CheckFailure`/`DeclInfo`), `--json` CLI flag, WASM returns JSON
- **Phase 3a**: Semantic metadata (`SemInfo`/`SemInfoKind`), 6 resolution sites in elab, position-indexed queries
- **Phase 3b**: REPL (`doxa repl`), immutable `ReplSession`, expression + declaration accumulation, prelude seeded
- **Phase 3c**: LSP server (`doxa lsp`), stdio JSON-RPC, diagnostics/hover/definition/completion, Content-Length framing
- **Package split**: `doxa` (kernel, 15 files), `doxa_tooling` (CLI + WASM + LSP, 10 files + bin + web)
- **LSP integration**: opencode config at `opencode.json`, `doxa` binary on PATH via `dart pub global activate`

### Kernel Hardening (branch `doxa-extended`)
- **Phase 14.5**: Quotient types (`TQuot`/`TQuotMk`/`TQuotLift`), ι-reduction, identity-only VQuotMk conv, parser + elaboration, 31 tests
- **Elaborator stack fix**: `SApp` elaboration refactored to iterative (was recursive, overflowed at depth ~1000; now stack-safe at depth 5000+)
- **Benchmarking**: `tool/benchmark.dart` with CLI flags, real + synthetic workloads, AOT comparison

## Running the Benchmark

```shell
# JIT
dart run tool/benchmark.dart --only=proofs --repeat=5 --warmup=3

# AOT
dart compile exe tool/benchmark.dart -o tool/benchmark_aot
./tool/benchmark_aot --only=proofs --repeat=5 --warmup=3

# Full suite
./tool/benchmark_aot --repeat=3 --warmup=2

# Church depth stress
./tool/benchmark_aot --only=church --depth=100,500,1000,5000 --repeat=2 --warmup=1
```

- `alloc_profile.dart` — phase breakdown + eval/conv micro-benchmarks
- `parse_ast_profile.dart` — per-declaration parse cost, throughput
- `parse_deep_profile.dart` — lexer overhead, scaling analysis
- `stack_stress.dart` — linear-time + stack-safety verification (pre-existing)
